# dice-_rolling_python
Dice Roll Simulator  A simple Python-based Dice Roll Simulator that allows users to roll two dice repeatedly until they choose to quit. The program uses Python's built-in random module to generate random numbers between 1 and 6, simulating the behavior of real dice.

#Features
Roll two dice simultaneously.
Generates random values between 1 and 6 for each die.
Allows multiple rolls without restarting the program.
Accepts both uppercase and lowercase user input.
Handles invalid input gracefully.
Displays a thank-you message when the user exits.
#How It Works
The program asks the user whether they want to roll the dice (y/n).
If the user enters y, two random dice values are generated and displayed.
If the user enters n, the program exits with a thank-you message.
Any other input is treated as invalid, and the user is prompted again.
